📝 A real notepad

Tabs, multi-cursor, column select, bookmarks, folding, line operations, encodings and line endings, markdown preview.

⌨️ Notepad++ keys

Ctrl+D, Ctrl+Shift+Up, Alt+drag, F2 bookmarks, Ctrl+Q comments, and more. Remap any of them in Preferences.

📁 Your notes folder

Always in the sidebar, next to any other folder you open. Sync it with Syncthing; nothing is locked in.

🎨 Themes

nss dark and light, Solarized, Nord, Gruvbox and more, or your own colours, the same on every device.

💾 Never loses work

Unsaved edits survive closing the app; new tabs live as scratch files; changes on disk are caught before saving over them.

🔒 Private

Single owner, hashed password, IP bans, signed cookies, no tracking. Android has a fingerprint lock and a share target.

Run your own

  1. Get it

    git clone https://gitlab.com/niharokz/mnemostxt.git && cd mnemostxt
cp .env.example .env

  2. Set the login in .env

    docker compose run --rm mnemostxt hash-password   # MNEMOSTXT_PASSWORD_HASH
openssl rand -hex 32                              # MNEMOSTXT_SECRET

    Plus MNEMOSTXT_USER and NOTE_PATH (your notes folder). A demo account is optional.

  3. Start it behind HTTPS

    docker compose up -d --build

    Point your proxy at mnemostxt:8080 and sign in.

Everything else is in the README.
